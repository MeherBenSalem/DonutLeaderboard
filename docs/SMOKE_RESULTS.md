## Bundled vs runtime libraries

Paper/Spigot do **not** ship HikariCP, MySQL Connector/J, or SQLite JDBC in the server jar. With `plugin.yml` `libraries:`, Paper’s **SpigotLibraryLoader** downloads them into the server `libraries/` folder on first enable (observed on Paper 1.20.1 and 1.21.11 smoke logs).

## Jar size note

The release plugin jar is ~98 KB (plugin + minimized bStats). Database drivers are not shaded.
